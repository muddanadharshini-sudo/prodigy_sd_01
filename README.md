# Prodigy_SD_01
This project was completed as part of the Prodigy InfoTech Software Development Internship.
## Task Description
This Python program converts temperatures between Celsius, Fahrenheit, and Kelvin based on the user's input.
## Features
- Convert Celsius to Fahrenheit and Kelvin
- Convert Fahrenheit to Celsius and Kelvin
- Convert Kelvin to Celsius and Fahrenheit
- User-friendly command-line interface
## Technologies Used
- Python 3
## How to Run
1. Clone this repository.
2. Open the project folder.
3. Run the following command:
```bash
python temperature_converter.py
```
4. Enter the temperature value.
5. Select the unit (C, F, or K).
6. View the converted temperature.
